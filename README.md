# 水道修理・リフォーム会社 採用LP（制作実績）

公開ページ：https://kazuma-oki.github.io/portfolio-aquros-recruit-lp/

水道修理・リフォーム会社のスタッフ採用ランディングページ。既存LPの改善提案から、デザイン改修・実装・納品準備までを担当。
広告（Google検索・Instagram・TikTok）からの流入を想定し、スマートフォンでの見やすさと公式LINEへの応募導線を重視した。

## 担当範囲
- 既存LPの課題整理と改善方針の提案
- デザイン改修（Figma で編集 → コードへ反映する往復の仕組みを構築）
- 実装（スマートフォン・タブレット・PC対応）
- 公開・計測の準備（公開手順書、GA4・GTM・広告タグの計測設計）

## 主な工夫
- 水をモチーフにした動き：読み込みの進み具合に合わせて水位が上がる読み込み画面、スクロールに合わせて背景の水位が上がる演出、控えめな泡
- ファーストビューの写真3枚の切り替え（読み込み完了後に開始）
- 公式LINEへの応募ボタンを5か所に配置（メニュー・選考の流れ・お問い合わせ・追従ボタン・PCの右側）
- iOS Safari での表示の揺れ・ちらつき対策（メニュー表示時の背面固定の方式など）
- 計測：ボタンのクリックを場所つきで GTM に送り、流入元別に LINE 遷移率を見られるよう設計
